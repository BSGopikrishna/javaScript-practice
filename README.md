## 🚀 How to Run
Want to run the code locally? Follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BSGopikrishna/javaScript-practice.git
   ```
2. **Open the project:**
   Navigate into the folder and open the `.html` files in your favorite web browser.
3. **View the output:**
   Open the **Developer Tools** (Right-click -> Inspect -> Console) to see the JavaScript output.
